# Code of conduct

We want everyone, from a radiologist to a talking drummer, to feel welcome here.

- **Be respectful.** Disagree about the content, never attack the person.
- **Be honest.** Don't pass off opinions as facts, and say if you have a commercial interest.
- **Protect privacy.** Don't share other people's personal information.
- **No harassment, hate speech, spam or self-promotion disguised as help.**

**Reviewers may edit, decline or remove any contribution that breaks these rules,** and may block repeat offenders. Report problems through "Suggest an edit" (type: Other) or to the maintainer's contact on the About page.

*Larger community?* Consider adopting the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in place of this short version.
