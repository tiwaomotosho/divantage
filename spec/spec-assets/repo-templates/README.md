# Repository templates (V2.3)
Copy these into the root of the public repository when you create it (22 §3.7):

| File | Purpose |
|---|---|
| `LICENSE` | MIT licence for the code (D-061). Replace `{COPYRIGHT HOLDER}` first. Use AGPL-3.0 instead if the owner chooses it. |
| `LICENSE-CONTENT.md` | CC BY 4.0 for catalogue content |
| `CONTRIBUTING.md` | How to suggest, edit and review |
| `CODE_OF_CONDUCT.md` | Behaviour expected from everyone |
| `.github/ISSUE_TEMPLATE/*.yml` | GitHub issue forms that mirror the in-app suggestion types |
| `.github/PULL_REQUEST_TEMPLATE.md` | Reviewer checklist (20 §7) |
| `.github/workflows/ci.yml` | Reference CI: rebuild, verify no hand edits, validate, search tests (16 §11) |
| `.github/labels.json` | Labels used by the Function and reviewers |
